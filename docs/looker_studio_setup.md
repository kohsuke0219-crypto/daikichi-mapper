# Looker Studio セットアップ手順

スプレッドシートにデータが入った状態から、地図ダッシュボードを完成させるまでの手順です。

## 1. レポート作成

1. [Looker Studio](https://lookerstudio.google.com/) を開く
2. 「空のレポート」を選択
3. データを追加 → **Google スプレッドシート** → 該当のスプレッドシート → `stores` シートを選択
4. 「追加」をクリック

## 2. 地理型フィールドの設定

スプレッドシート上は `latitude` `longitude` が単なる数値カラムなので、Looker Studio に「これは緯度経度ですよ」と教える必要があります。

1. 左上の「リソース > 追加済みのデータソースの管理」を開く
2. `stores` データソースの「編集」をクリック
3. 計算フィールドを追加（右上の「フィールドを追加」）:

   ```
   フィールド名: lat_lng
   数式: CONCAT(latitude, ",", longitude)
   ```

4. 作成した `lat_lng` の **タイプ** を「地理 > 緯度、経度」に変更
5. 「完了」で保存

## 3. バブルマップを追加

1. レポートのキャンバスに戻る
2. メニューバーから「グラフを追加 > Google マップ > バブルマップ」
3. 設定パネルで以下を指定:

   - **ロケーション**: `lat_lng`
   - **ツールチップ**: `name`（店舗名）
   - **色のディメンション**: `region` または `prefecture`（任意。地区ごとに色分けしたい場合）
   - **サイズの指標**: 空欄でOK（全店舗を同じサイズで表示）

4. グラフをドラッグして広げる

## 4. フィルタコントロールを追加

商圏分析に便利なフィルタを置きます。

1. 「コントロールを追加 > プルダウンリスト」を3つ追加:
   - コントロールフィールド: `region` → 地区フィルタ
   - コントロールフィールド: `prefecture` → 都道府県フィルタ
   - コントロールフィールド: `closed_days` → 定休日フィルタ（曜日別商圏を見るとき便利）

2. 「コントロールを追加 > 入力ボックス」を1つ追加:
   - コントロールフィールド: `name` → 店舗名検索

## 5. 一覧テーブルを追加

地図の横に店舗リストを置くと、相互に動いて使いやすくなります。

1. 「グラフを追加 > 表」
2. ディメンション: `name`, `prefecture`, `address`, `phone`, `business_hours`
3. 並べ替え: `name` 昇順

## 6. 自動更新の設定

スプレッドシートが更新されると、Looker Studio は **15分以内** に自動で反映されます。  
即時反映したい場合は、レポート右上の「⋮ > データを更新」をクリック。

## 7. (発展) 商圏分析の追加レイヤー

### 競合店レイヤー

別シート `competitors` に競合の座標を入れ、Looker Studio で別のデータソースとして追加します。同じ地図ウィジェットに重ねるには:

1. 既存のバブルマップを選択し、「+ 別のシリーズを追加」
2. 競合シートをデータソースに指定、色を変える（例: 赤）
3. 大吉店舗（青）と競合店（赤）が同じ地図に並ぶ

### 半径バッファ

Looker Studio のバブルマップでは半径バッファ（円）を直接描けません。本格的にやるなら:

- **Google Earth Engine + Earth Engine for Looker Studio**: 円バッファや人口統計と組み合わせ可能
- **QGIS**: スプレッドシートをCSVエクスポート → QGIS でバッファ生成 → 地理院タイル等と重ねて分析
- **kepler.gl** (無料): スプレッドシートを直接読み込み、ヒートマップ・3Dマップが豊富

商圏分析を本気でやるなら QGIS か kepler.gl をサブツールとして併用するのがおすすめです。

## トラブルシューティング

### 地図に何も表示されない

- `lat_lng` のタイプが「地理 > 緯度、経度」になっているか確認
- `latitude` や `longitude` が空文字列の行が混ざっていないか（Looker Studio はそういう行をスキップする）

### データが古いまま

- スプレッドシートのデータソース設定で「キャッシュを更新」をクリック
- 自動更新は最大15分のラグがある

### 一部の店舗が地図に出ない

- スプレッドシートの該当行の `latitude` / `longitude` を確認
- ジオコーディングが失敗していたら、その住所表記に問題がある可能性大（建物名や階数が悪さをすることがある）
- 手動で正しい座標を入れて、次回スクレイピング時にもキャッシュとして使われるようにする
