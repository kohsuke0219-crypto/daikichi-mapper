# 共有（Google Apps Script + スプレッドシート）セットアップ手順

地図の **お気に入り地点** と **NGエリア（出店しない市区町村・黒塗り）** を
**複数端末・複数人で共有** するための設定です。
バックエンドは Google スプレッドシート、橋渡しは Google Apps Script の Web アプリです。
（無料・追加サービス不要。既存の Google アカウントで完結します）

> 既にお気に入り共有を設定済みの方へ: 機能追加のたびに **`favorites_sync.gs` を最新コードに貼り替えて再デプロイ**してください（「デプロイを管理 > 編集 > 新バージョン > デプロイ」。URLは変わりません）。データは種類ごとに別シートへ自動保存されます:
> - お気に入り → `favorites` シート
> - NGエリア → `ng_areas` シート
> - 物件（🏠 物件URL/写真URL/家賃/備考）→ `properties` シート
>
> 地図側の設定（URL/トークン）はそのままでOKです。**物件共有を使うにはこの再デプロイが必要**です（未対応のままだと物件はローカル保存のみになります）。

## 1. 共有用スプレッドシートを用意
- 新規でも既存（買取大吉のスプレッドシート）でもOK。
- お気に入りは自動で **`favorites` という別シート（タブ）** に保存されるので、既存データには影響しません。

## 2. Apps Script を貼り付け
1. そのスプレッドシートを開く → メニュー **拡張機能 > Apps Script**
2. エディタの中身を全部消し、`favorites_sync.gs` の内容を貼り付け
3. （任意）書き込み保護したい場合は `const TOKEN = '';` に好きな合言葉を入れる
   例: `const TOKEN = 'daikichi2026';`
4. 💾 保存

## 3. ウェブアプリとしてデプロイ
1. 右上 **デプロイ > 新しいデプロイ**
2. 種類（歯車）→ **ウェブアプリ**
3. 設定:
   - 説明: 任意（例: favorites）
   - **実行するユーザー: 自分**
   - **アクセスできるユーザー: 全員**（ログイン無しで読み書きするため必須）
4. **デプロイ** → 初回は権限の承認を求められるので承認
5. 表示される **ウェブアプリのURL**（`https://script.google.com/macros/...../exec`）をコピー

## 4. 地図に設定（各端末で1回ずつ）
1. 地図左下「🛠 商圏ツール」→ **⚙ 共有設定** を開く
2. **URL欄** にコピーしたウェブアプリURLを貼る
3. TOKEN を設定した場合は **トークン欄** に同じ合言葉を入れる
4. **「保存して同期」** を押す → 状態が「🟢 共有中」になれば成功
5. 同じURL（とトークン）をチームに渡し、各自の端末でも 1〜4 を実施

これで、ある端末で追加・編集・削除したお気に入りが、他端末でも見られるようになります。
（他端末の変更は約60秒ごとに自動取得。すぐ反映したいときは「今すぐ同期」）

## 仕様・注意
- **保存先**: スプレッドシートの `favorites` シート（id / lat / lng / comment / author / createdAt / updatedAt）
- **動作**: 端末側はまず即時にローカル表示（楽観更新）し、裏でスプレッドシートへ同期。オフラインでもローカルには残り、次回オンライン時の操作で送信されます。
- **URLは公開ソースに埋め込みません**。各端末の localStorage にのみ保存されるため、GitHub 上の公開コードにURLは出ません（＝URLを知るチームだけがアクセス可能）。
- **セキュリティ**: 「全員」公開のため、URL（+トークン）を知っていれば誰でも読み書きできます。URLはチーム内に限定して共有してください。より厳密なアクセス制御が必要なら Firebase 等への移行を検討します。
- **コード更新時**: Apps Script を修正したら「デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン: 新バージョン > デプロイ」で更新（URLは変わりません）。

## トラブルシュート
- 「🟢 共有中」にならない / 同期できない:
  - URL末尾が `/exec` になっているか（`/dev` ではない）
  - デプロイのアクセス権が「全員」か
  - ブラウザのコンソール（F12）に出るエラーメッセージを確認
- 反映が遅い: 「今すぐ同期」を押す（自動は約60秒間隔）
